# Recallio — Premium Flashcards & Spaced Repetition

A tiny, dependency-free study app built with vanilla HTML, CSS and JavaScript.

## What it does

- Four starter decks (Spanish, JavaScript, World Capitals, Biology)
- 3D card-flip study session with Again / Hard / Good / Easy rating
- Live stats: cards reviewed, retention %, best streak, cards due
- Insights view with a retention ring and per-deck bars
- Keyboard shortcuts: `Space` flip, `1`–`4` rate, `R` restart deck
- Progress persisted in `localStorage` — no backend, no tracking

## Stack

- Vanilla HTML / CSS / JS, no frameworks, no CDN, no build step
- Responsive from 360px up, semantic HTML with aria labels

## Run locally

Open `index.html` in any modern browser.
